# Parallel learning plan

## Knowledge dependency map

For each topic: prerequisite → concept → competition decision → observable exercise. Mark needed now / learn during competition / optional deepening. Do not infer current competence from an old profile.

| Topic | Main resource + exact chapter | Backup | Verified evidence/date | Prerequisites/language | Estimated study time | Competition-linked exercise |
|---|---|---|---|---|---|---|

## Five-hour week

Fit the current concept, hands-on exercise and explanation into five hours. Adjust to the actual gap; do not require a fixed time allocation or a backup resource when the main source already fits.

## Mastery evidence

Keep resource_prepared / user_attempted / independently_explained separate. Ask 3–5 focused teach-back questions with a concrete task. No response leaves learning pending; research continues. Never have AI answer on the user's behalf and record it as mastery.
