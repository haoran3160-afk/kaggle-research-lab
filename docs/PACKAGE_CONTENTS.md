# Public package contents

This release packages the complete active workflow. Its source is the private workflow mainline as of 2026-11-08, plus the system-research and stage-aware continuation improvements developed alongside it. The public project has independent Git history and versioning.

| Requirement | Included location |
|---|---|
| Entry point and host metadata | `SKILL.md`, `agents/openai.yaml` |
| Learning, prerequisite mapping, inspected resources and practice | `modules/learning.md`, `assets/LEARNING.md` |
| Rules, specifications and stable project instructions | `modules/specs.md`, `assets/COMPETITION.md` |
| Open implementations, papers and usable alternatives | `modules/intelligence.md` |
| Protocol/strong/deployment baselines and evaluation by competition type | `modules/baseline.md` |
| Independent experts, open exploration and bounded experiments | `modules/research.md`, `assets/EXPERIMENT.json` |
| Own improvements, harness research, memory and reliability | `references/system-research.md` |
| Actual integration gains, regressions, adoption and pivots | `modules/progress.md` |
| Recoverable execution, quota distinctions and productive waiting | `modules/execution.md` |
| Stage-aware automation content and user-owned schedule | `modules/execution.md` |
| Git branches, commits, PRs, review and delivery | `modules/delivery.md` |
| Final selection, deadline and retrospective | `modules/closeout.md`, `assets/RETROSPECTIVE.md` |
| Seven outcome-based effectiveness questions | `references/effectiveness.md` |
| Lightweight state and readonly legacy record import | `scripts/workspace.py`, `references/workspace.md` |
| Installation and behavioral checks | `scripts/install_skill.py`, `tests/` |
| Seven selected upstream skills and supporting resources | `upstream/`, `references/adapters.md`, `THIRD_PARTY_NOTICES.md` |
| Cross-competition lessons | `docs/LESSONS.md` |

The installer includes the active references, all four templates, the complete bundled upstream slices, and licensing files. Project-facing README, development tests and documentation remain in the cloned source.

Private histories, personal paths, raw receipts, archives of superseded dispatchers, credentials, competition datasets, weights and official judging material are not part of the public runtime. Transferable findings are retained in the modules and lessons. The active workflow does not rely on those private files.

The original local skill name `kaggle-research-loop` remains usable for ongoing projects. The public skill is installed as `kaggle-research-lab`; publication does not rename or interrupt existing project automation.
